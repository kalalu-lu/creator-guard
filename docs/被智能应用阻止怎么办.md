# 双击 start.bat 被“智能应用控制”阻止怎么办

> 先判断弹窗：
>
> - 有 **更多信息 → 仍要运行**：这是 SmartScreen，点“更多信息”再点“仍要运行”。
> - 只有“确定”，没有“仍要运行”：这是智能应用控制（Smart App Control），按下面做。

---

## 最快方案：用 start.py，不碰 .bat

打开 PowerShell（不是 cmd 也行）：

```powershell
cd C:\CreatorGuard
py -3 start.py
```

如果提示找不到 `py`：

```powershell
python start.py
```

它会自动：

1. 创建 `.venv`
2. 安装依赖
3. 启动 `http://127.0.0.1:8765`
4. 打开浏览器

停止：`Ctrl + C`。

不想自动开浏览器：

```powershell
python start.py --no-browser
```

然后手动打开 <http://127.0.0.1:8765/api/health>。

---

## 方案 2：先解除文件锁定

如果项目是从网上下载的 zip：

1. 右键 zip → **属性**
2. 勾选 **解除锁定 / Unblock**
3. 确定
4. 重新解压

已经解压了：

```powershell
cd C:\CreatorGuard
Get-ChildItem -Recurse -File | Unblock-File
```

然后再试 `start.bat`。

---

## 方案 3：从终端运行 .bat

```powershell
cd C:\CreatorGuard
cmd /c start.bat
```

有时智能应用控制只拦“资源管理器双击”，由 `cmd.exe` 读取可以跑。

---

## 如果连 Python 也被阻止

用 Microsoft Store 安装 Python：

<https://apps.microsoft.com/detail/9ncvdn91xzqp>

安装后重开 PowerShell：

```powershell
python --version
cd C:\CreatorGuard
python start.py
```

---

## 不建议做的事

- 不要连续双击几十次。
- 不要下载“破解版 Python/免安装 Python”。
- 不要把 `.bat` 改成 `.exe` 再双击；未签名 exe 更容易被拦。
- 不要为了这个项目关闭 Defender 实时保护。
- 不建议关闭“智能应用控制”。关闭后通常要重置/重装 Windows 才能重新打开。

---

## 启动成功后

看到：

```text
Uvicorn running on http://127.0.0.1:8765
```

浏览器打开：

<http://127.0.0.1:8765/api/health>

看到 `"ok": true` 即可。

然后按 [一页纸启动卡](一页纸启动卡.md) 继续加载扩展。
