# 一页纸启动卡（打印/照着点）

> 详细解释看 [保姆级安装教程](保姆级安装教程.md)。这一页只列“现在做什么”。

---

## 1. 装 Python

- 下载：<https://www.python.org/downloads/windows/>
- 安装时勾选 **Add python.exe to PATH**
- 验证：

```powershell
python --version
```

看到 `3.10` 或更高即可。

> 如果暂时不想装模型：跳到第 3 步，双击 `start-mock.bat`，只跑规则层和界面，先把扩展跑通。

---

## 2. 装 Ollama

- 下载：<https://ollama.com/download>
- 安装后打开 PowerShell：

```powershell
ollama pull qwen2.5:7b-instruct
```

- 验证：

```powershell
ollama run qwen2.5:7b-instruct "用一句中文回答：准备好了吗？"
```

---

## 3. 放项目

把 `creator-guard` 放到：

```text
C:\CreatorGuard
```

确认有：

```text
C:\CreatorGuard\start.bat
C:\CreatorGuard\server\
C:\CreatorGuard\extension\
```

---

## 4. 启动服务

双击：

```text
C:\CreatorGuard\start.bat
```

> 没装 Ollama、只想先看界面：改双击 `start-mock.bat`。

> **如果双击被“智能应用控制”阻止**：不要反复双击，改用 PowerShell：
>
> ```powershell
> cd C:\CreatorGuard
> py -3 start.py
> ```
>
> 或者先试 `cmd /c start.bat`。详细说明看 [保姆级安装教程](保姆级安装教程.md) 第 5.4 节，或 [被智能应用阻止怎么办](被智能应用阻止怎么办.md)。

看到：

```text
Uvicorn running on http://127.0.0.1:8765
```

**这个黑窗口不要关。**

浏览器打开验证：

<http://127.0.0.1:8765/api/health>

看到 `"ok": true` 和 `"model_present": true` 即可。

---

## 5. 加载扩展

1. Chrome 地址栏：`chrome://extensions`
2. 打开 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选：

```text
C:\CreatorGuard\extension
```

5. 把 Creator Guard 固定到工具栏。

---

## 6. 测试连接

点扩展图标：

- 地址：`http://127.0.0.1:8765`
- 点 **测试连接**
- 显示 **本地服务 + 模型已就绪** 即可。

第一次设置：

| 开关 | 设置 |
|---|---|
| 自动展开未读私信 | 关 |
| 自动滚动收集评论 | 关 |
| 遮住恶意私信预览 | 开 |
| 高风险私信不展开 | 开 |

---

## 7. 试私信

打开：

<https://message.bilibili.com/>

等 3 秒，右上角出现 **私信守护**。

应该看到：

- 恶意私信：红色标签，预览被盖住
- 合作：蓝色标签
- 建议：绿色标签
- 当前打开的恶意会话：聊天区被白色遮罩盖住

---

## 8. 试评论

打开任意 B 站视频，等 3 秒，右下角出现 **评论守护**。

点：

1. **收集当前屏**
2. **立即更新统计**

应看到：

- 有效建议 Top 3
- `xx% 的评论集中在「...」`
- 评论构成条形图

---

## 9. 确认没问题后，再开自动

先观察 3–7 天。没有异常，再打开：

- 自动展开未读私信（每日上限先设 20）
- 自动滚动收集评论（最多 30 屏）

**不要**加自动回复、自动拉黑、自动举报。

---

## 10. 出问题先看这三处

1. `start.bat` 黑窗口的最后 30 行。
2. 浏览器 `F12` → Console 里 `[CreatorGuard]` 开头的报错。
3. `chrome://extensions` 里 Creator Guard 有没有红色报错。

把这三样发我，基本都能定位。
